# 🎵 Music Vibes - Frontend

Music Vibes is a modern MERN Stack music streaming web application that allows users to explore albums, discover artists, manage music collections, and securely access protected features through user authentication.

## 🚀 Features

- User Registration
- User Login with Authentication
- Protected Routes
- Browse Music Albums
- Explore Popular Artists
- Music Collection CRUD Operations
- Contact Form
- Responsive Navigation
- Modern User Interface
- Local Storage Authentication

## ⚙️ Installation

Clone the repository

```bash
git clone <repository-url>
```

Go to the frontend folder

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

Start the application

```bash
npm start
```

The application runs at:

```
http://localhost:3000
```

## 🔐 Authentication

The frontend communicates with the backend API for:

- User Registration
- User Login
- JWT Authentication
- Protected Routes

After successful login, authentication details are stored in Local Storage.

---

## 🌐 Backend API

The frontend communicates with:

```
http://localhost:5000
```

Backend endpoints include:

- POST /register
- POST /login
- GET /albums
- POST /albums
- PUT /albums/:id
- DELETE /albums/:id
- POST /contact
