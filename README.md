# Muzic Application 🎵

A MERN stack music application where users can explore albums,
artists, register/login, and manage music-related data.

## Tech Stack
Frontend:
- React.js
- CSS
- React Router

Backend:
- Node.js
- Express.js
- MongoDB

## Setup

Clone repository

Install dependencies:

cd backend
npm install

cd frontend
npm install

Run backend:
npm start

Run frontend:
npm start
